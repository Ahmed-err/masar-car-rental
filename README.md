# Masar — مسار

Car rental website for Cairo: fleet browser, live price calculator with add-ons and long-rental discounts, booking without prepayment.

**Live demo:** https://sarmadax.com/work/masar/

## Features
- Fleet browser that swaps cars by category, with paint colours
- Live receipt with insurance, driver, child seat and delivery add-ons
- Automatic 10% weekly and 20% monthly discounts
- Pick-up and return dates synced to the calculator

## Stack
HTML5, CSS, vanilla JavaScript, GSAP + ScrollTrigger, inline SVG

## Run locally
No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
